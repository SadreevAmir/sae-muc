## old-prototype/

The Colab-era prototype that first reproduced "Calibrating Verbal Uncertainty
as a Linear Feature to Reduce Hallucinations" (Meta FAIR, 2025). Assembled
under time pressure — hard-coded `/content/...` paths, duplicated modules, no
configs, no tests. Useful as a navigational map to which part of the pipeline
lives where, and as a source of formulas to cross-check against the paper.

The active code lives in `src/sae_muc/`. See the root `README.md` and
`QUICKSTART.md`.
